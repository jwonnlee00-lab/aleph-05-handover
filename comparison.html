제출 전 남은 확인

- 전체 시간 상한: 두 기록 구간은 60분 안이지만, 전체 종료·전달까지 포함한 정확한 시간은 자료 부족으로 확정 불가. 호출 수는 두 원본 기록 모두 80회 이하이다.

- 공개 접근: 공개 URL의 무로그인 접근 결과는 제출 확인 기록에서 확인한다. 기존 사이트와 구분되는 별도 제출본이다.

- 개인정보·비밀값: 이 비교표에는 모델·서비스명, 실제 사람 이름·계정·이메일·비밀값을 넣지 않았다. 원본 소스에는 인물·계정 출처 표기가 있고 이미지·Git 이력도 포함하므로 저장소 전체에 대해 0건을 인증하지 않는다. 공개 전 전체 텍스트·이미지·이력 점검 필요(T05-C37/C38).

- 자료 완전성: 원본 ZIP 전체 파일을 지정 커밋과 바이트 대조해 모두 일치했다. 원본 인계 문서 SHA256과 Y가 받은 문서의 기록 해시도 일치했다. 대화 전문은 사용하지 않았다.

- 보완 필요: 도구 선택 기준 문장의 학생 확인, 전체 종료 시각과 전체 실행 회차 기록, 공개 URL 확인, 실기기 M04·M07·M08.
